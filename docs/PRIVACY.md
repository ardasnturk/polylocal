# Privacy

Polylocal is designed so that your text stays on your Mac. This page lists what the app touches and where it goes.

## Translation

All translation, rewriting, and completion runs on-device, using a model on your disk and a local engine (the bundled `llama-server`, or Ollama if you choose it). The engine listens only on a local port. No text is sent to any server.

## Network

The app makes two kinds of network requests:

- **Model downloads** from Hugging Face (the URLs in [models/catalog.json](../models/catalog.json)), only when you start one. Downloads are verified with SHA-256.
- **Update checks** (Sparkle): once a day, if you allow it, the app downloads the version list `appcast.xml` from `raw.githubusercontent.com`, and the update DMG from GitHub Releases when you install one. Sparkle's anonymous system profile is not enabled; the request carries only the usual app name and version in its user agent. Updates are verified with an EdDSA signature and Apple's code signature before they are installed. You can turn checking off in Settings → About.

No text you translate is ever part of these requests. If you use Ollama, any model downloads it performs are handled by Ollama itself.

There is no telemetry, analytics, or crash reporting.

## Stored data

| Data | Location | Notes |
|---|---|---|
| Models | `~/Library/Application Support/Polylocal/Models/` | Downloaded model files |
| Settings, rules, glossary | `UserDefaults` (`dev.polylocal.app`) | |
| Translation history | `~/Library/Application Support/Polylocal/history.json` | **Off by default.** File permissions 0600 (readable only by your user). Can be cleared from the history view |

Data from earlier builds under `~/Library/Application Support/Translater/` is moved to the `Polylocal` folder automatically.

## Reading text from other apps

Polylocal uses the macOS Accessibility API.

- **Shortcuts (⌘C C, ⇧⌘C C, writing assistant):** text is read only when you press the shortcut.
- **Inline suggestions and sentence completion:** text is read only in apps or websites for which you have created a rule.
- **Secure and password fields** (`AXSecureTextField`) are never read.
- Text is never changed without your confirmation (Tab, ↩, ⌘↩, or a click).

## Clipboard

When Accessibility cannot read or write text directly, the app falls back to the clipboard (simulated ⌘C / ⌘V) and restores your previous clipboard contents afterwards. These temporary writes are marked with the [nspasteboard.org](http://nspasteboard.org) `TransientType` and `AutoGeneratedType` types, so clipboard managers that honor them do not record them.

## Diagnostic log

The app logs to the unified log via `os.Logger` with subsystem `dev.polylocal.app`. Entries contain metadata only (for example the frontmost app's bundle ID, the action, which capture or replace path was used, the target language), never the text itself.

```bash
log stream --predicate 'subsystem == "dev.polylocal.app"'
```
